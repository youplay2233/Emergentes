# TecEmergetes

## Evidencias de prácticas en Unity

Este sitio documenta los avances realizados en Unity a través de dos prácticas.

---

## Práctica 1 — Creación de escenarios

El objetivo de la primera práctica fue construir y organizar escenarios dentro de Unity.

Se trabajó con dos entornos:

### Estadio de fútbol

El estadio corresponde al proyecto principal. Se creó el escenario, se distribuyeron los elementos del campo y las gradas, y se dejó preparado para continuar agregando funciones en prácticas posteriores.

![Vista general del estadio](imagenes/estadio-1.png)

### Parque

También se creó un parque con diferentes zonas y objetos distribuidos dentro de la escena.
