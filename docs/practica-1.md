# Práctica 1 — Creación de escenarios en Unity

## Objetivo

El objetivo de esta práctica fue aprender a crear, organizar y visualizar escenarios dentro de Unity, trabajando con distintos objetos y elementos de una escena 3D.

## Desarrollo

Durante la práctica se desarrollaron dos escenarios principales: un estadio de fútbol y un parque.

### 1. Estadio de fútbol

El estadio fue desarrollado como el proyecto principal. Se trabajó en la distribución del campo, las gradas, las porterías y otros elementos del entorno.

Esta actividad permitió practicar:

- Colocación de objetos dentro de la escena.
- Movimiento, rotación y escala.
- Organización visual de un escenario.
- Distribución de elementos dentro de un espacio 3D.

### 2. Parque

El segundo escenario consistió en la creación de un parque con diferentes áreas y objetos.

Se organizaron caminos, zonas verdes y diferentes elementos decorativos para formar un entorno completo.

Esta parte permitió practicar:

- Construcción de un escenario utilizando diferentes assets.
- Organización de objetos dentro de la jerarquía de Unity.
- Distribución de diferentes zonas dentro de una misma escena.
- Visualización del escenario desde distintas perspectivas.

## Resultado

Al finalizar la práctica se obtuvieron dos escenarios funcionales dentro de Unity: un estadio de fútbol y un parque.

Estos escenarios sirvieron como base para la siguiente práctica, en la que se agregaron animaciones.

## Conclusión

La práctica permitió comprender mejor el proceso de construcción y organización de escenas dentro de Unity. También ayudó a familiarizarse con la manipulación de objetos y con la preparación de un escenario para agregar nuevas funciones posteriormente.
