PRÁCTICA 01

Rigidbody y gravedad

Comprender cómo participa un objeto en la simulación física de Unity, diferenciando el papel de Transform, Collider, Rigidbody y Script.

Física

Simulación conceptual: aunque cambie la masa, los 3 cubos caen igual por gravedad.
Inspector · Cube

Idea clave

La masa sí afecta la respuesta a fuerzas e impactos, pero no hace que un objeto caiga más rápido por gravedad. Is Kinematic impide que la física controle el objeto.

Preguntas de comprobación

  • ¿Cuál es la diferencia entre Collider y Rigidbody?
  • ¿Qué ocurre al activar Is Kinematic?
  • ¿La masa cambia la velocidad de caída?
  • ¿Para qué sirven las Constraints?

Objetivo

Construir una escena de caída y observar cómo actúan la gravedad y las propiedades físicas de Rigidbody.

Pasos

Crear un plano con Collider, añadir 3 objetos, activar Rigidbody, modificar masa, Drag e Is Kinematic y registrar lo observado.

Resultado esperado

Los objetos caen por gravedad; si el objeto es cinemático, permanece inmóvil y solo se movería por script o por manipulación directa.

PRÁCTICA 02

Colliders y colisiones

Configurar superficies físicas, comparar Discrete y Continuous, y entender cómo un trigger puede disparar otra acción.

Colisiones
Scene · CollisionTrack
La pista representa piso, rampa, paredes laterales y tres obstáculos.
Inspector · Sphere Rigidbody

Comparación

Discrete consume menos recursos y sirve para la mayoría de los objetos. Continuous reduce el riesgo de que un objeto rápido atraviese una superficie.

Tipos de Collider

  • Box Collider: cajas, paredes y plataformas.
  • Sphere Collider: pelotas y objetos redondos.
  • Capsule Collider: personajes.
  • Mesh Collider: geometría irregular, más costoso.
Game · TriggerWorld
▲
Al entrar al trigger se crean planetas y asteroides
Representación de la práctica: una nave activa un trigger y se generan objetos.
Scripts
public class ActivadorBoton : MonoBehaviour {}

[RequireComponent(typeof(BoxCollider))]
public class BotonPorContacto : MonoBehaviour
{
  [SerializeField] private GameObject objetoObjetivo;

  private void Awake()
  {
    GetComponent<BoxCollider>().isTrigger = true;
  }

  private void OnTriggerEnter(Collider other)
  {
    if (other.GetComponentInParent<ActivadorBoton>() == null)
      return;

    if (objetoObjetivo != null)
      objetoObjetivo.SetActive(!objetoObjetivo.activeSelf);
  }
}

Lógica

El collider del objeto receptor se pone como trigger. Cuando un objeto con el componente activador entra, se ejecuta una acción, por ejemplo encender, aparecer o alternar otro objeto.

PRÁCTICA 03

Objetos y Script · Cañón autónomo

Comprender formatos de objetos en Unity y aplicar programación básica en C# mediante un cañón que instancia balas físicas.

Scripts
Game · CannonLab
PuntoDisparo
Se modela el flujo real de la práctica: prefab → instantiate → fuerza → autodestrucción.
Inspector + Scripts

Formatos de objetos

  • FBX: geometría, materiales básicos, rigging y animaciones.
  • OBJ: ideal para objetos estáticos, sin huesos ni animaciones.
  • BLEND: archivo nativo de Blender; Unity puede convertirlo durante la importación.

Variables vistas

  • public: aparece en el Inspector.
  • private: solo visible dentro del script.
  • Tipos: int, float, bool, string, GameObject.
public class ControlCañon : MonoBehaviour
{
  public GameObject prefabBala;
  public Transform puntoSalida;
  public float fuerzaDisparo = 1000f;

  public void Disparar()
  {
    GameObject nuevaBala = Instantiate(
      prefabBala,
      puntoSalida.position,
      puntoSalida.rotation
    );

    Rigidbody rb = nuevaBala.GetComponent<Rigidbody>();
    rb.AddForce(puntoSalida.forward * fuerzaDisparo);
  }
}

public class Bala : MonoBehaviour
{
  private void Start()
  {
    Destroy(gameObject, 3f);
  }
}

Prefab de la bala

Esfera pequeña con Rigidbody y material. Se guarda en Project y luego se instancia desde el script del cañón.

Punto de disparo

Un Empty GameObject hijo del cañón, ubicado en la punta, define dónde nace la bala y evita que aparezca dentro del cilindro.

Conceptos aplicados

Instantiate, Destroy, GetComponent, variables públicas, funciones, Rigidbody y AddForce.

PRÁCTICA 05

Latencia y protocolos en CPS y XR

Entender la latencia como la suma de retrasos en el ciclo sensor → red → cómputo → actuador, y relacionarla con XR, donde una M2P mayor a 20 ms puede provocar mareo.

Conceptos clave

Latencia en CPS

Se compone de latencia de sensado, de red/transmisión, de cómputo y de actuación.

Determinismo

En CPS es más importante un retardo bajo y predecible que un gran ancho de banda.

XR

Si el movimiento de la cabeza no coincide con la imagen en menos de 20 ms, aparece el mareo cinetósico.

UDP

Prioriza velocidad. Si se pierde un paquete de posición, el siguiente llega enseguida.

WebRTC

Permite streaming P2P de audio, video y datos con latencia baja.

OpenXR / MQTT

OpenXR estandariza la interacción con visores; MQTT es útil para datos ligeros en MR + IoT.

Medios físicos relevantes

Wi‑Fi 6E / 7 reduce interferencia y latencia para visores inalámbricos. 5G URLLC habilita realidad aumentada y comunicación confiable en exteriores.

PROYECTO INTEGRADOR

JARVIS · Asistente de ingeniería en realidad mixta

Proyecto conceptual orientado a usar Meta Quest 3 y Unity + OpenXR para abrir modelos 3D, inspeccionarlos, seleccionar piezas y preparar modificaciones asistidas por voz e inteligencia artificial.

Problema

Editar o inspeccionar un modelo 3D suele exigir usar herramientas de escritorio complejas. La idea es llevar parte de ese flujo a una experiencia inmersiva e intuitiva.

Objetivo

Visualizar modelos tipo STL en MR, permitir selección de componentes, controlarlos con interfaz espacial y usar comandos de voz para ejecutar acciones sobre el modelo.

Salida esperada

Una beta funcional donde el usuario carga un modelo, selecciona una parte y ejecuta una acción inicial como separar, mover o resaltar una pieza.

Flujo del usuario

  1. Cargar un modelo 3D.
  2. Visualizarlo en realidad mixta.
  3. Seleccionar piezas o subconjuntos.
  4. Dar un comando por voz o desde UI.
  5. Ejecutar una acción: separar, resaltar, mover o reemplazar.
