[RequireComponent(typeof(BoxCollider))]
public class BotonPorContacto : MonoBehaviour
{
  private void OnTriggerEnter(Collider other)
  {
    if (other.GetComponentInParent<ActivadorBoton>() == null)
      return;

    Presionar();
  }
}

PRÁCTICA 03

Cañón autónomo

Crear un cañón que instancia balas físicas, les aplica fuerza y elimina cada proyectil después de unos segundos.

C# + PREFABS
Scene · CannonLab
PuntoDisparo

Recreación del prefab de bala y del punto de salida del cañón.

ControlCañon.cs
public void Disparar()
{
  GameObject nuevaBala = Instantiate(
    prefabBala,
    puntoSalida.position,
    puntoSalida.rotation
  );

  Rigidbody rb = nuevaBala.GetComponent<Rigidbody>();
  rb.AddForce(puntoSalida.forward * fuerzaDisparo);
}
Flujo

Instantiate → GetComponent<Rigidbody> → AddForce → Destroy a los 3 s.

Prefab

Bala

Esfera pequeña con Rigidbody y material, guardada como prefab.

Spawn

PuntoDisparo

Empty GameObject en la boca del cañón para evitar que la bala nazca dentro del modelo.

Force

Disparo

La fuerza se aplica en la dirección forward del punto de salida.

UDP

Velocidad primero

Útil cuando un paquete viejo deja de ser relevante y el siguiente estado llegará inmediatamente.

WebRTC

Tiempo real

Audio, video y datos P2P con baja latencia para colaboración remota XR.

OpenXR

Interfaz común

Estándar para que aplicaciones XR funcionen sobre distintos visores sin reescribir toda la integración.

Idea principal

En sistemas XR importa más una latencia baja y predecible que simplemente tener mucho ancho de banda. El jitter también afecta la estabilidad perceptual.
