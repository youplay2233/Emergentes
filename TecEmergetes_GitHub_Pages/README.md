# TecEmergetes

Repositorio de documentación y evidencias de las prácticas realizadas en **Unity**.

El trabajo se desarrolló utilizando dos escenarios principales:

- **Parque:** escenario creado para practicar la construcción de entornos y posteriormente agregar una animación a la rueda de la fortuna.
- **Estadio de fútbol:** proyecto principal, utilizado para desarrollar el escenario y agregar una animación sencilla al portero.
